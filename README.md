# Java · Fundamentos de programación

Ejercicios introductorios para practicar métodos, condiciones, arrays y excepciones en Java.

## Contenido

| Archivo | Conceptos |
| --- | --- |
| `src/Calculadora.java` | Operaciones aritméticas y división por cero |
| `src/Estadisticas.java` | Arrays, bucles, media, mínimo y máximo |
| `src/ConversorTemperatura.java` | Fórmulas, métodos y validación de temperaturas |

## Ejecución

Instala un **JDK 11 o superior**. Desde la raíz del repositorio, ejecuta cada ejemplo:

```bash
java src/Calculadora.java
java src/Estadisticas.java
java src/ConversorTemperatura.java
```

La calculadora muestra 16, 8, 48 y 3, además de detectar la división por cero.
El ejemplo de notas muestra media 8, mínimo 6 y máximo 10.
El conversor muestra que 0 °C son 32 °F y 212 °F son 100 °C.
